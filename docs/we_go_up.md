### 1. 우리 걱정은 딱히 넣어둬 빨리
*(歌曲時間戳：00:30)*

#### 核心翻譯與表達 (Translation)
- **自然韓文表達**：우리 걱정은 딱히 넣어둬 빨리（我們的事你少操心，快把你的擔心收起來吧！）
- **韓文敬語/正式表達**：
  - **日常敬語（해요體）**：저희 걱정은 딱히 넣어두세요 빨리. / 저희 걱정은 안 하셔도 돼요.
  - **正式敬語（하십시오體）**：저희 걱정은 딱히 넣어두십시오. / 저희 염려는 하지 마십시오.
- **羅馬拼音**：`u-ri geok-jeong-eun ttak-hi neo-eo-dwo ppal-li`

#### 句子結構與文法拆解 (Grammar Breakdown)
整個句子結構為：**代名詞 + 名詞 + 主題助詞 + 副詞 + 複合動詞祈使句 + 狀態副詞**：
- **우리**：第一人稱代名詞「我們（平語/非謙稱）」。在敬語中會謙稱換成「저희」。
- **걱정**：名詞「擔心、顧慮、憂慮」。
- **-은**：主題助詞（帶收音名詞後接 -은），用於對比或強調主題（「至於我們的擔心嘛…」）。
- **딱히**：副詞，原意為「明確地、特別地」。在口語中極常出現在帶有否定意圖的語境中，表示「倒也沒特別…」、「犯不著…」。
- **넣어둬**：由動詞 **넣다**（放進去）+ 輔助動詞文法 **-어/아 두다**（放置、維持某狀態以備後續）融合而成：
  - `넣-` + `-어` -> `넣어`（放入）
  - `두-` + 現在非格式體語尾 `-어` -> `두어` 縮寫為 `둬`（放著吧）。
  - 合起來的慣用語「걱정을 넣어두다」字面是「把擔心塞進抽屜收起來」，口語就是「別瞎操心」、「少多管閒事」。
- **빨리**：副詞「快點、趕緊」。

#### 發音與連音解析 (Pronunciation & Rules)
- **實際發音**：`[우리 걱정은 딱히 넣어둬 빨리]` -> `[우리 걱쩡은 따키 너어둬 빨릴]`
- **發音規則說明**：
  1. **平音緊音化（경음화）**：單字「걱정」中，前面的收音 `ㄱ` [k] 促使後面的平音 `ㅈ` [tɕ] 發生緊音化，發成濃音 `[걱쩡]`。
  2. **激音化（격음화 / 자음축약）**：在「딱히」中，前面字的收音 `ㄱ` 遇上後面的子音 `ㅎ`，兩者結合成送氣激音 `ㅋ` [kʰ]，因此實際發音為 `[따키]`，絕對不可分開發成 [딱-히]。
  3. **母音脫落與連音**：「넣어」中的 `ㅎ` 遇到後面的母音 `어` 時，`ㅎ` 脫落無聲化，聽感接近流暢的 `[너어]`。

#### 實用補充與文化小知識 (Notes & Nuances)
- **使用情境**：
  - 霸氣、自信的反擊語調。當別人質疑「你們這樣會不會太冒險？」時，這句話就是帥氣的回嗆：「你先顧好你自己，少管我們的閒事！」
  - 日常熟人之間開玩笑也可以用：「내 걱정은 넣어둬~（哎呀免操心我啦～）」。
- **常見錯誤提醒**：
  - 許多初學者常將副詞「빨리（快點）」與形容詞原型「빠르다（快的）」搞混。修飾動詞動作時一律要用副詞型態「빨리」。
- **相似/替換表達**：
  - `신경 쓰지 마`：別放在心上 / 跟你沒關係。
  - `오지랖 부리지 마`：別多管閒事 / 少多嘴（語氣較重）。

### 2. 어림없거든
*(歌曲時間戳：00:46)*

#### 核心翻譯與表達 (Translation)
- **自然韓文表達**：어림없거든（門都沒有！/ 休想！/ 差得遠呢！）
- **韓文敬語/正式表達**：
  - **日常敬語（해요體）**：어림없거든요.
  - **正式敬語（하십시오體）**：어림없습니다.
- **羅馬拼音**：`eo-rim-eop-geo-deun`

#### 句子結構與文法拆解 (Grammar Breakdown)
整個句子結構為：**合成形容詞詞幹 + 說明/反駁終結語尾**：
- **어림**：名詞，指「估計、大約的計數、推量」。
- **없다**：形容詞，指「沒有、不存在」。
- **어림없다**：固定合成形容詞，字面原意是「連邊都沾不上、連估算的份量都沒有」，引申為「根本不可能實現、做夢、妄想、門都沒有」。
- **-거든**：終結語尾。在口語對話中，接在動詞/形容詞詞幹後，具有強烈的「告知對方事實」或「帶有驕傲、反駁、賭氣色彩」的語氣，相當於中文的「…要知道才不可能呢！」、「才不會那樣呢！」。

#### 發音與連音解析 (Pronunciation & Rules)
- **實際發音**：`[어림없거든]` -> `[어리멉꺼든]`
- **發音規則說明**：
  1. **連音規則（연음화）**：「어림」的收音 `ㅁ` 移到「없」字母音 `어` 的初聲，變成 `[어리멉...]`。
  2. **雙收音（겹받침 ㅄ）簡化與緊音化**：「없」的底部是雙收音 `ㅄ`，當遇到後方子音 `ㄱ` 時：
     - 收音本身發代表音 `ㅂ`。
     - 另外的 `ㅅ` 促使後面的 `ㄱ` 緊音化變成濃音 `ㄲ`。
     - 因此「-없거든」聽起來是乾淨俐落的 `[업꺼든]`。

#### 實用補充與文化小知識 (Notes & Nuances)
- **使用情境**：
  - 朋友想借走你心愛的東西、或是對手狂妄挑戰你時，轉頭送他一句「어림없거든!（想得美！/ 門都沒有！）」，既傲嬌又俐落。
- **相似/替換表達**：
  - `꿈도 꾸지 마`：做夢去吧 / 連夢都別想做。
  - `말도 안 돼`：太不像話了 / 怎麼可能。

### 3. 어이없거든
*(歌曲時間戳：00:47)*

#### 核心翻譯與表達 (Translation)
- **自然韓文表達**：어이없거든（真是傻眼！/ 太荒唐莫名其妙了！）
- **韓文敬語/正式表達**：
  - **日常敬語（해요體）**：어이없거든요.
  - **正式敬語（하십시오體）**：어이없습니다.
- **羅馬拼音**：`eo-i-eop-geo-deun`

#### 句子結構與文法拆解 (Grammar Breakdown)
整個句子結構為：**慣用語源名詞 + 否定形容詞 + 告知/反駁語尾**：
- **어이**：名詞。語源來自石磨把手（맷돌 손잡이，又稱 어처구니）。古時若要磨豆子卻發現把手掉了，會讓人陷入手足無措的巨大荒謬感。
- **없다**：形容詞「沒有」。
- **어이없다**：形容詞，形容某件事「極度荒謬、令人哭笑不得、無話可說、傻眼」。
- **-거든**：口語反駁/宣告語尾（同上句，形成雙重押韻排比）。

#### 發音與連音解析 (Pronunciation & Rules)
- **實際發音**：`[어이없거든]` -> `[어이업꺼든]`
- **發音規則說明**：
  - 同樣符合雙收音 `ㅄ` 的代表音規則（留 `ㅂ`）與後方子音緊音化（`ㄱ` -> `ㄲ`），唸作 `[어이업꺼든]`。

#### 實用補充與文化小知識 (Notes & Nuances)
- **韓劇超高頻詞彙**：
  - 韓國人在日常生活、韓劇吵架、遇到離譜事件時，最常脫口而出的就是「진짜 어이없어!（真的太傻眼了！）」。
  - 在《WE GO UP》裡，接在「어림없거든（門都沒有）」後面，形成連珠炮反擊黑粉與競爭者的押韻爽感。
- **相似/替換表達**：
  - `어처구니없다`：荒謬絕倫（更偏書面/正式語感）。
  - `기가 차다`：氣到說不出話來 / 令人咋舌。

### 4. 우린 보란듯이
*(歌曲時間戳：02:22)*

#### 核心翻譯與表達 (Translation)
- **自然韓文表達**：우린 보란듯이（我們會爭氣地做給全世界看 / 昂首示威般地）
- **韓文敬語/正式表達**：
  - **日常敬語（해요體）**：저희는 보란듯이 증명할게요.
  - **正式敬語（하십시오體）**：저희는 보란듯이 보여드리겠습니다.
- **羅馬拼音**：`u-rin bo-ran-deu-si`

#### 句子結構與文法拆解 (Grammar Breakdown)
整個句子結構為：**代名詞縮寫 + 揚眉吐氣慣用副詞片語**：
- **우린**：第一人稱複數「우리（我們）」加上主題助詞「는」的口語縮寫（`우리는 -> 우린`）。在 K-POP 歌詞中極少唱完整的「우리는」，幾乎百分之百會縮寫為單音節的「우린」來對齊節拍。
- **보란듯이**：是韓國極具代表性的勵志慣用語，來自於動詞「보다（看）」的間接引用祈使態：
  - `보라고 하다`（叫大家看）縮寫為 `보라다`。
  - 冠詞形 `보란` + 模樣名詞 `듯`（好像…一樣）+ 副詞格尾音 `-이`。
  - 字面直譯是「如同叫大家『看著吧！』似地」，引申為**「爭氣地、昂首挺胸地、做給看扁自己的人看以證明實力」**。

#### 發音與連音解析 (Pronunciation & Rules)
- **實際發音**：`[우린 보란듯이]` -> `[우린 보란드시]`
- **發音規則說明**：
  - 收音 `ㅅ` 的口語弱化：「듯」帶有收音 `ㅅ`，但在現代標準語流暢發音時，遇後方母音 `이` 經常順暢連為 `[드시]`。

#### 實用補充與文化小知識 (Notes & Nuances)
- **文化意境**：
  - 韓國文化中強調「한（恨 / 奮發圖強的韌性）」，當受到外界批評、被低估時，韓國人最常對自己說的勉勵話就是「보란듯이 성공할 거야（我一定會爭氣地成功給你們看！）」。
- **相似/替換表達**：
  - `당당하게`：堂堂正正地 / 昂首自信地。
  - `멋지게 증명하다`：漂亮地證明自己。

### 5. 불을 지필 거야
*(歌曲時間戳：02:24)*

#### 核心翻譯與表達 (Translation)
- **自然韓文表達**：불을 지필 거야（我們會點燃烈火 / 引爆全場狂潮！）
- **韓文敬語/正式表達**：
  - **日常敬語（해요體）**：불을 지필 거예요.
  - **正式敬語（하십시오體）**：불을 지필 것입니다.
- **羅馬拼音**：`bu-reul ji-pil geo-ya`

#### 句子結構與文法拆解 (Grammar Breakdown)
整個句子結構為：**名詞 + 受格助詞 + 動詞詞幹 + 未來意志推測語尾**：
- **불**：名詞「火、火焰」。
- **-을**：受格助詞（前面詞有收音接 -을，無收音接 -를），標註「불」是此句中被點燃的對象。
- **지피-**：動詞「지피다（生火、添柴柴火、引火）」，常用於「불을 지피다」。在比喻意境中，指的是點燃熱情、煽動熱血風暴。
- **-(으)ㄹ 거야**：韓語最核心的未來式句型：
  - 未來定語詞尾 `-(으)ㄹ` + 依存名詞 `것`（事物）+ 口語非敬語指定詞 `이야`。
  - 口語中 `것이야` 劇烈濃縮為 `거야`。
  - 表達說話者**「無比確信的個人意志」**或**「必然發生的未來走向」**（我一定會這麼做）。

#### 發音與連音解析 (Pronunciation & Rules)
- **實際發音**：`[불을 지필 거야]` -> `[부를 지필 꺼야]`
- **發音規則說明**：
  1. **連音（연음화）**：「불」的收音 `ㄹ` 往後滑動到「을」的母音位置，發成 `[부를]`。
  2. **冠詞形緊音化（관형사형 ㄹ 뒤의 된소리）**：在未來語尾 `-(으)ㄹ` 後方遇到的子音 `ㄱ, ㄷ, ㅂ, ㅅ, ㅈ`，必須強制緊音化！因此「지필」後面的「거야」必須發成濃音 `[꺼야]`，絕對不可唸成鬆音 [거야]。

#### 實用補充與文化小知識 (Notes & Nuances)
- **K-POP 舞台金句**：
  - 演唱會上偶像常對台下大喊：「오늘 밤 무대에 불을 지필게요!（今晚我們要點燃整個舞台！/ 把舞台炸裂！）」
- **相似/替換表達**：
  - `불태우다`：燃燒殆盡 / 燃燒一切（例：무대를 불태우다 燃炸舞台）。
  - `열기를 더하다`：增添現場狂熱氣氛。

### 6. 세상 꼭대기에
*(歌曲時間戳：02:27)*

#### 核心翻譯與表達 (Translation)
- **自然韓文表達**：세상 꼭대기에（站在世界之巔 / 在世界的最高峰處）
- **韓文敬語/正式表達**：
  - **日常敬語（해요體）**：세상 꼭대기에서 만나요.（我們世界之巔相見吧）
  - **正式敬語（하십시오體）**：세상 꼭대기에 서겠습니다.（我將立於世界之巔）
- **羅馬拼音**：`se-sang kkok-dae-gi-e`

#### 句子結構與文法拆解 (Grammar Breakdown)
整個句子結構為：**名詞 + 名詞（空間頂點） + 靜態位置格助詞**：
- **세상**：名詞「世界、人間世」。
- **꼭대기**：名詞「頂部、頂峰、高處邊緣」（例如：산꼭대기 山頂、건물 꼭대기 大樓樓頂）。
- **-에**：副詞格助詞（位置/方向），接在處所後表示「在該目標點、朝該方向」。

#### 發音與連音解析 (Pronunciation & Rules)
- **實際發音**：`[세상 꼭대기에]` -> `[세상 꼭때기에]`
- **發音規則說明**：
  - 緊音化：單字「꼭대기」中，初聲本身就是濃音 `ㄲ`，而第一音節收音 `ㄱ` 又再次讓第二音節的 `ㄷ` 發生緊音化，唸作 `[꼭때기]`。

#### 實用補充與文化小知識 (Notes & Nuances)
- **進階替換字彙（純韓文 vs 漢字詞）**：
  - `꼭대기` 是純韓語固有詞，極富視覺高度感。
  - 其對應的漢字詞為 `정상（頂上）`（例：세상의 정상에 在世界頂點）。
- **相似/替換表達**：
  - `가장 높은 곳에`：在最高的地方。
  - `원탑 (One-Top)`：口語指唯一霸主、無人能及的頂流。

### 7. 우린 판을 바꿀 Game changer
*(歌曲時間戳：02:30)*

#### 核心翻譯與表達 (Translation)
- **自然韓文表達**：우린 판을 바꿀 Game changer（我們是徹底扭轉遊戲規則的局勢顛覆者！）
- **韓文敬語/正式表達**：
  - **日常敬語（해요體）**：저희는 판을 바꿀 게임 체인저예요.
  - **正式敬語（하십시오體）**：저희는 판을 바꿀 게임 체인저입니다.
- **羅馬拼音**：`u-rin pa-neul ba-kkul Game changer`

#### 句子結構與文法拆解 (Grammar Breakdown)
整個句子結構為：**主詞縮寫 + 棋局受詞 + 動詞冠詞未來修飾型 + 外來語名詞**：
- **우린**：`우리 + 는`（我們）。
- **판**：原指「棋盤、牌局、版圖」，引申為整個「局勢、整個業界遊戲生態」。
- **-을**：受格助詞。
- **바꿀**：動詞「바꾸다（改變、替換）」加上**未來時態名詞修飾詞尾 `-(으)ㄹ`**：
  - `바꾸-` + `-ㄹ` = `바꿀`（將要去改變的…、有能力翻轉的…）。
  - 修飾後方名詞「Game changer（局面顛覆者）」。
- 整個慣用語「판을 바꾸다」就是指**「打破現狀、改寫既定格局」**。

#### 發音與連音解析 (Pronunciation & Rules)
- **實際發音**：`[우린 판을 바꿀 Game changer]` -> `[우린 파늘 바꿀 ...]`
- **發音規則說明**：
  - 連音化：「판」的收音 `ㄴ` 移至後方受格助詞「을」的初聲母音位置，流暢連音成 `[파늘]`。

#### 實用補充與文化小知識 (Notes & Nuances)
- **生活必學慣用語「판」的用法**：
  - `판을 키우다`：把盤子做大 / 擴大事業格局。
  - `판이 깨지다`：局破了 / 談判破局。
- **相似/替換表達**：
  - `새로운 역사를 쓰다`：書寫全新歷史。
  - `흐름을 뒤집다`：逆轉潮流風向。

## 💡 總結：從《WE GO UP》學會的 3 大實用韓語核心法則

1. **口語縮寫無處不在**：
   - `나는` 縮寫為 `난`
   - `우리는` 縮寫為 `우린`
   - `것이야` 縮寫為 `거야`
   聽 K-POP 歌一定要對這些單音節縮寫敏銳，才能抓到主詞與句尾。
2. **長型否定 `-지 않다` 與短型否定 `안` 的不可混用性**：
   - `안` 放在動詞前（如：안 멈춰）
   - `-지 않다` 放在動詞詞幹後（如：멈추지 않아），且帶雙收音 `ㄶ`。
3. **收音與連音的魔鬼細節**：
   - 遇後方母音連上去（연음화，如 `판을 -> 파늘`、`불을 -> 부를`）。
   - 遇後方子音產生緊音化（된소리，如 `걱정 -> 걱쩡`、`지필 거야 -> 지필 꺼야`）。
